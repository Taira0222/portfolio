## 背景

- 中身が古いまま（土木・塾・独学が中心、学習用の作品）で、今の仕事が 1 行しかない
- 画像が 36MB あり、開くのが遅い
- 見た目（バーの意匠）は残す。2026-11-24 に別の見た目を 2 回試し、今のほうがいいと決まった

## やること

| 項目 | 中身 |
|---|---|
| 言語ごとの URL | 英語は `/portfolio/`、日本語は `/portfolio/ja/`。ブラウザの言語での自動切り替えはやめ、URL だけで決める。相手に合わせて URL を送り分けられる |
| 自己紹介 | 今の仕事をざっくり（会社名・数字・中身の細部は書かない）。経歴は 1 文だけ |
| 経歴の欄 | タイムラインをやめる（自己紹介の 1 文に移す） |
| 技術スタック | 今の仕事の技術（Python・FastAPI・Vue・AWS・Terraform）を先に。AI（Claude Code・MCP・ローカル LLM）を足し、テストの欄は外す |
| 作品 | スペイン語の単語帳を足し、Todo アプリと Qiita のブログを外す。Juku Cloud を featured にして先頭に。詳しい画面に「仕組み」の構成図を入れる |
| 画像 | 見た目を変えずに小さくする |

## やらないこと

- 一番上の言葉（CIVIL × EDU × SOFTWARE）は今のまま。言葉は後で決める
- 家のサーバーの構成（入口・ソフトの版）は書かない

## 完了条件

- `/portfolio/` が英語、`/portfolio/ja/` が日本語で開き、切り替えのボタンでもう一方の URL に移る
- リンクのプレビュー（og:title など）がそれぞれの言語で出る
- 画像の合計が数 MB 以下
- lint・型チェック・テスト・ビルドが通る
