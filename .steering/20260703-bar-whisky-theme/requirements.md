# 要求内容 — バー/ウイスキーテーマの導入

## 背景

現状のUIは shadcn/ui デフォルトの無彩色トークンがほぼそのまま残っており、テーマ（一貫した視覚的個性）が知覚されない。

- `--primary` はほぼ黒、`--secondary` / `--accent` / `--muted` はほぼ白（彩度ゼロ）
- 唯一の有彩色 `--brand`（青紫）の使用箇所はホバー枠線など計3箇所のみ
- HeroBackground の `rgba(59,130,246,...)` や Career / TechStack の `sky-100` / `blue-50` などがトークン外にハードコード
- フォント指定がなくシステムフォント任せ
- `.dark` トークンは定義済みだが切り替え手段がなく、実質ライトモード固定

## 変更・追加する機能の説明

サイト全体に「バー/ウイスキー」を主題とした統合テーマを導入する（運営者の趣味に根ざした意匠）。

ヒーローの「Civil Eng × Edu × Software Eng =」という式を「3つの原酒のブレンド」というウイスキーの物語に読み替え、趣味の意匠とキャリアの語り口を一致させる。

| モード | 世界観                          | 基調                                                                 |
| ------ | ------------------------------- | -------------------------------------------------------------------- |
| ダーク | W1 スピークイージー（夜のバー） | 漆黒 `#17120E` × 琥珀 `#D98E32` × 真鍮 `#B8863B`                     |
| ライト | W2 ボトルラベル（昼のラベル）   | 生成り紙 `#F3EBDB` × オックスブラッド `#7C2D1E` × ゴールド `#A67C2E` |

両モードは琥珀系アクセント×セリフ体見出しを共有し、一貫した世界観を保つ。

### スコープ

1. **カラートークンの差し替え** — `src/index.css` の light / dark 両トークンセットをテーマカラーに置換（shadcn トークン構造は維持）
2. **テーマ切替機能の追加** — システム設定（`prefers-color-scheme`）追従＋ヘッダーのトグルで手動切替、選択は `localStorage` に永続化
3. **ハードコード色の回収** — HeroBackground の `rgba(...)` を琥珀のグローに変更、`sky-100` / `blue-50` 等をトークン参照へ置換
4. **フォント導入** — 英字見出し用セリフ体＋和文見出し用明朝体を追加（本文は現行のシステムサンセリフを維持）
5. **テーマ固有のディテール** — メニュー罫線（◆付きライン）、ヒーローの琥珀グロー、「Est. 2019」等のアイブロウ文言、セクション見出しの意匠

### スコープ外

- レイアウト構造・セクション構成の変更
- コンテンツ（文言・画像）の大幅な変更（アイブロウ等の小さな追加文言は除く）
- 多言語対応の変更（追加文言は既存の i18n 構造に従う）

## ユーザーストーリー

- 訪問者として、サイトを開いた瞬間に運営者の個性（バー/ウイスキーの世界観）が伝わるデザインを見たい。それにより他のポートフォリオとの差別化を感じられる。
- 訪問者として、OSの外観設定に合ったモード（ライト/ダーク）で快適に閲覧したい。また好みに応じて手動でも切り替えたい。
- 採用担当者・クライアントとして、意匠が読みやすさを損なわない、品のあるデザインで経歴・作品を確認したい。

## 受け入れ条件

- [ ] ライトモードが W2（生成り紙×オックスブラッド×ゴールド）、ダークモードが W1（漆黒×琥珀×真鍮）のパレットで表示される
- [ ] 初回訪問時は `prefers-color-scheme` に追従し、ヘッダーのトグルで切替・`localStorage` に永続化される
- [ ] 再読み込み時にテーマのフラッシュ（FOUC）が発生しない
- [ ] 全セクション（Hero / About / TechStack / Portfolio / Career / Header / Footer）で旧テーマの青系ハードコード色が残っていない
- [ ] 見出しにセリフ体（英字・和文）が適用され、本文の可読性は維持される
- [ ] 両モードで本文・見出しのコントラストが WCAG AA（4.5:1）を満たす
- [ ] 既存のテスト・リント・型チェックがすべて通る
- [ ] モバイル〜デスクトップの各ブレークポイントで表示崩れがない

## 制約事項

- Tailwind CSS 4 の `@theme` / CSS変数によるトークン管理を維持する（shadcn/ui コンポーネントとの互換性）
- フォントはセルフホスト（`@fontsource` 等）とし、外部CDNへのランタイム依存を増やさない。日本語フォントはサブセット版を使い、パフォーマンスを損なわない
- GitHub Pages（ベースパス `/portfolio/`）でのホスティングを前提とする
- グロー等の装飾は `prefers-reduced-motion` を尊重し、過度なアニメーションを追加しない
